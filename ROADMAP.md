# Data Analyst Career Roadmap

This document defines the learning sequence, skills, milestones, and completion standards for this career-transition programme.

The roadmap is followed in order. A phase is not marked complete until its learning tasks and practical assessments have been reviewed.

## Learning Principles

- Learn one concept at a time.
- Understand the reasoning behind each method, not just the steps.
- Attempt assignments independently before reviewing solutions.
- Practise with realistic business datasets and scenarios.
- Explain findings in clear business language.
- Revise work based on feedback.
- Use free learning resources wherever practical.

## Phase 01 — Advanced Excel

**Goal:** Build strong spreadsheet analysis, data-cleaning, reporting, and dashboard skills.

Topics:
1. Excel tables, structured references, and workbook best practices
2. Data cleaning and preparation
3. Text, date, logical, and lookup functions
4. Conditional calculations: SUMIFS, COUNTIFS, AVERAGEIFS
5. Dynamic array functions and modern lookup methods
6. Sorting, filtering, data validation, and conditional formatting
7. PivotTables, PivotCharts, and slicers
8. Power Query for repeatable data preparation
9. Data modelling and Power Pivot fundamentals
10. KPI reporting and interactive dashboards

Practical work:
- Clean and analyse enquiry or helpline records.
- Measure call volumes, response rates, resolution rates, and complaint trends.
- Build an interactive operational performance dashboard.

**Milestone:** Complete a reviewed Excel analysis project and explain its key findings.

## Phase 02 — SQL

**Goal:** Retrieve, transform, aggregate, and analyse relational data confidently.

Topics:
1. Databases, tables, rows, columns, and data types
2. SELECT, DISTINCT, and column aliases
3. WHERE, comparison operators, and logical conditions
4. ORDER BY and LIMIT
5. Aggregate functions and GROUP BY
6. HAVING
7. CASE expressions
8. Joins: INNER, LEFT, RIGHT, and FULL
9. Subqueries and common table expressions
10. Date, text, and null-handling functions
11. Window functions and ranking
12. Query practice using business questions

Practical work:
- Analyse customer enquiries, complaints, dealer performance, and activation records using SQL.

**Milestone:** Solve a set of business analysis questions independently and submit reviewed SQL queries.

## Phase 03 — Power BI

**Goal:** Build reliable data models, measures, and interactive business reports.

Topics:
1. Power BI Desktop interface and workflow
2. Connecting to data sources
3. Power Query and data transformation
4. Data modelling and relationships
5. Star schema fundamentals
6. DAX basics and calculated columns
7. Measures and filter context
8. Time intelligence
9. Visual selection and report design
10. Drill-through, tooltips, bookmarks, and interactions
11. KPI design and dashboard storytelling
12. Publishing and sharing fundamentals

Practical work:
- Build an operational dashboard for enquiries, complaints, dealer performance, and GPS/IoT activation.

**Milestone:** Deliver a documented Power BI project with a clear data model, validated measures, and business insights.

## Phase 04 — Statistics for Data Analysis

**Goal:** Use statistical reasoning to interpret data and make sound decisions.

Topics:
1. Population, sample, and types of data
2. Mean, median, mode, and percentiles
3. Range, variance, and standard deviation
4. Distributions and outliers
5. Sampling and sampling bias
6. Probability fundamentals
7. Normal distribution
8. Confidence intervals
9. Hypothesis testing and p-values
10. Correlation versus causation
11. Regression fundamentals
12. Choosing and interpreting appropriate metrics

Practical work:
- Interpret service performance, customer satisfaction, response times, and operational trends without overstating what the data proves.

**Milestone:** Complete a statistics case study and explain the results in plain business language.

## Phase 05 — Python for Data Analysis

**Goal:** Use Python to clean, explore, analyse, and communicate findings from datasets.

Topics:
1. Python environment, variables, and data types
2. Operators, conditions, and loops
3. Lists, tuples, sets, and dictionaries
4. Functions and reusable code
5. Reading and writing files
6. NumPy fundamentals
7. Pandas Series and DataFrames
8. Data cleaning and missing values
9. Filtering, sorting, grouping, and aggregation
10. Merging and reshaping datasets
11. Exploratory data analysis
12. Data visualisation with Matplotlib and Seaborn
13. Basic analytical scripting and project organisation

Practical work:
- Analyse a realistic operational dataset using Pandas and communicate the most important findings.

**Milestone:** Complete a reproducible Python analysis project with clear code, outputs, and conclusions.

## Phase 06 — Business Analytics

**Goal:** Translate business problems into measurable questions, analysis, and recommendations.

Topics:
1. Understanding business problems
2. Defining KPIs and metrics
3. Building an analytical approach
4. Funnel and conversion analysis
5. Trend and variance analysis
6. Segmentation and cohort thinking
7. Root-cause analysis
8. Operational and customer analytics
9. Forecasting fundamentals
10. Data storytelling and recommendations

Practical work:
- Investigate a business problem such as low IoT activation, delayed complaint resolution, or declining enquiry conversion.

**Milestone:** Present an evidence-based business recommendation supported by analysis.

## Phase 07 — Portfolio Projects

**Goal:** Demonstrate job-ready skills through a small number of complete, well-documented projects.

Expected project standards:
- A clear business problem and objective
- A documented dataset and data dictionary
- Data cleaning and preparation steps
- Appropriate analysis and visualisations
- Key findings and actionable recommendations
- Reproducible files or queries where relevant
- A professional README explaining the project
- No confidential company or customer information

Portfolio projects should demonstrate a combination of Excel, SQL, Power BI, Python, and business analysis. Projects will be selected and developed after the relevant skills have been learned.

**Milestone:** Publish reviewed projects on GitHub that can be confidently discussed in interviews.

## Phase 08 — Interview and Career Preparation

**Goal:** Prepare to demonstrate analytical ability and communicate professional value to employers.

Topics:
1. Data Analyst role expectations and job descriptions
2. Excel, SQL, Power BI, Python, and statistics interview questions
3. Business case and analytical problem-solving questions
4. Explaining portfolio projects
5. Resume and LinkedIn improvement
6. GitHub portfolio presentation
7. Communicating insights in professional English
8. Mock interviews and feedback
9. Job search strategy and application tracking

**Milestone:** Have a reviewed resume, presentable portfolio, and demonstrated readiness through mock interviews.

## Phase Completion Standard

Each phase follows this cycle:

1. **Learn:** Understand the concepts.
2. **Practise:** Attempt focused exercises independently.
3. **Apply:** Solve realistic business problems.
4. **Submit:** Share the completed work for review.
5. **Improve:** Correct errors and strengthen the analysis.
6. **Complete:** Mark the phase complete only after the required work passes review.

## Progress Tracking

The phase status is maintained in `PROGRESS-TRACKER.md` and the repository README. Do not mark a phase complete based only on lessons viewed or tasks attempted.

---

**Guiding principle:** Learn → Practise → Apply → Analyse → Build → Improve
