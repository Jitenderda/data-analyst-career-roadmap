- [ ] All task requirements have been addressed.
- [ ] Calculations, formulas, queries, or code have been checked.
- [ ] The result is logically correct and reproducible.
- [ ] Findings are explained clearly.
- [ ] Business implications are supported by evidence.
- [ ] Feedback has been addressed.
- [ ] Work is documented appropriately for GitHub.
